## 🌐 How to Host on GitHub Pages (Step-by-Step)

Aapka GitHub username hai: **`KhushiGupta0104`**

### Step 1: Create GitHub Repository
1. Browser mein jao: **[https://github.com/new](https://github.com/new)**
2. Repository name daalo:
   ```text
   KhushiGupta0104.github.io
   ```
   *(Agar repository ka naam `KhushiGupta0104.github.io` hoga, toh GitHub isko aapki primary website banata hai)*.
3. Select **Public**.
4. Click **Create repository**.

### Step 2: Upload Files
1. Repo page par click karein **Add file** → **Upload files**.
2. Is folder se ye 3 files upload karein:
   - `index.html`
   - `style.css`
   - `profile.jpg`
3. Niche scroll karein aur **Commit changes** par click karein.

### Step 3: Enable GitHub Pages
1. Repo ke **Settings** tab par jayein.
2. Left menu mein **Pages** par click karein.
3. **Build and deployment** section mein check karein:
   - Source: **Deploy from a branch**
   - Branch: **`main`** / **`/(root)`**
   - Click **Save** (agar already saved hai toh wait karein).

### Step 4: Your Live URL
Within 1-2 minutes, aapki website live ho jayegi:
👉 **`https://khushigupta0104.github.io/`**
*(Yahi URL aapko submission mein dena hai)*.
